# Security Policy

## Supported versions

Security fixes are made only for the latest release of each zabuton-app
application. Please update to the latest release before reporting.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or
pull requests.

Report them privately instead:

- **GitHub**: open the repository's **Security** tab and choose **Report a
  vulnerability**, where it is available.
- **Email**: send the details to <github@amgsk.dev>.

Please include:

- the application and its version
- your operating system and how you installed the application
- the steps to reproduce the problem, and what an attacker could do with it

You will receive a reply within a week. Once the problem is confirmed, a fix is
released as soon as possible, and you will be credited in the release notes
unless you prefer not to be.
